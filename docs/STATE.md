## Catatan Bug Terselesaikan & Workaround (Anti-Mengulang Masalah)
- *Catatan #01 s/d #11:* Tercatat dari rilis v1.0.0 hingga v1.3.0.
- *Catatan #12:* **DNS di APK Tidak Berpengaruh Saat DNS HP Dimatikan (v1.3.0 -> Fixed v1.4.0)**: `GeckoView` menggunakan network stack C++ Mozilla Necko yang terpisah dari `OkHttp`. Solusi permanen: buat file `gecko-config.yaml` dengan `network.trr.mode: 3` (Strict DoH), `network.trr.uri: "https://1.1.1.1/dns-query"`, `network.trr.bootstrapAddress: "1.1.1.1"`, dan `security.OCSP.enabled: 0`, lalu muat melalui `GeckoRuntimeSettings.Builder().configFilePath(...)`.
- *Catatan #13:* **Video Streaming Fullscreen Berantakan di Layar HP Besar (v1.3.0 -> Fixed v1.4.0)**: `ContentDelegate.onFullScreen` belum diimplementasikan. Solusi permanen: hubungkan `onFullScreen` ke `BrowserTab.isFullScreen`, sembunyikan `BrowserOmnibox` dan seluruh `WindowInsets`, aktifkan `LAYOUT_IN_DISPLAY_CUTOUT_MODE_SHORT_EDGES` + `SCREEN_ORIENTATION_SENSOR_LANDSCAPE`, serta tambahkan `android:configChanges="orientation|screenSize|screenLayout|smallestScreenSize|keyboardHidden|uiMode"` di `AndroidManifest.xml`.
- *Catatan #14:* **Adblock Lolos & Terdeteksi Anti-Adblock (v1.3.0 -> Fixed v1.4.0)**: Pasang Built-in GeckoView WebExtension (`resource://android/assets/addons/zenvora_shield/`) melalui `runtime.webExtensionController.ensureBuiltIn(...)` yang memfilter sub-resource (`webRequest.onBeforeRequest`), mengalihkan script umpan anti-adblock ke data URL stub sukses, menyuntikkan bait spoofing (`window.canRunAds = true`, `FuckAdBlock` stub), serta memblokir pop-under `onNewSession` dan `AdblockEngine.isUrlBlocked()` di `BrowserSession.kt`.
- *Catatan #15:* **Glitch Hitam di Bawah & Search Bar Muncul-Hilang Sendiri Saat Scroll (v1.4.0 -> Fixed v1.5.0)**: Mengubah tinggi `BrowserGeckoView` via `AnimatedVisibility` di atas `SurfaceView` menyebabkan realokasi buffer permukaan C++ dan koordinat sentuh lokal bergeser `57.dp` setiap kali bar bersembunyi (memicu loop osilasi `onScrollUp`). Solusi permanen: jaga tinggi `BrowserGeckoView` tetap 100% konstan (`Modifier.fillMaxSize()`), pasang `pointerInput` pada `Box` induk statis dengan debounce `420ms`, dan geser `BrowserOmnibox` serta `BrowserGeckoView` menggunakan `Modifier.offset { IntOffset(0, ...) }`.
- *Catatan #16:* **Search Bar Ganda & Tombol Kembali di Layar (v1.4.0 -> Fixed v1.5.0)**: Hapus search bar tengah pada `ChromeNewTabPage` (cukup gunakan `BrowserOmnibox` utama di atas) dan hapus seluruh ikon `ArrowBack` / tombol `"Kembali"` di semua halaman (`TabOverviewSheet`, `HistoryBookmarkSheet`, `SettingsSheet`, `SecurityDetailDialog`, `UpdateDialog`) karena navigasi kembali ditangani penuh oleh tombol kembali bawaan HP (`BackHandler`).
- *Catatan #17:* **Adblock Masih Bocor di Situs Streaming & Video Fullscreen Redmi 9C (v1.4.0 -> Fixed v1.5.0)**: Perkuat `zenvora_shield` dengan arsitektur Brave Shields (100+ ad/pop-under network, heuristic keyword judi/slot, blokir TLD pihak ketiga mencurigakan, blokir `window.open` & click-hijacking di `document_start`, pembersihan overlay transparan `z-index` tinggi di atas video) serta tambahkan kontrol rasio layar penuh video khusus layar 20:9 Redmi 9C (`Pas Layar 20:9`, `Zoom Penuh`, `Rasio 16:9`) dan pemicu langsung `"Layar Penuh Video (20:9)"` di menu 3-titik.
- *Catatan #18:* **Video 720p+ Patah-Patah di Chipset Entry-Level, YouTube Mati di Latar Belakang, Fullscreen Player Custom Tidak Membesar & Posisi Kontrol Rasio Mengganggu UI YouTube (v1.5.0 -> Fixed v1.6.0)**:
  1. Pindahkan kontrol rasio video fullscreen dari `Alignment.TopEnd` ke `Alignment.TopCenter` agar tidak menutupi tombol pengaturan/kualitas YouTube di kanan atas.
  2. Buat `HardwareCodecDetector` berbasis `MediaCodecList(MediaCodecList.ALL_CODECS)` yang mendeteksi dekoder hardware fisik (`H.264`, `HEVC`, `VP9`, `AV1`) secara dinamis sesuai chipset HP (tanpa hardcode) + opsi `VideoCodecMode` di Setelan, serta jeda scanner DOM saat video sedang fullscreen.
  3. Aktifkan pemutaran latar belakang YouTube/streaming dengan men-spoof `document.visibilityState = 'visible'`, `document.hidden = false`, memblokir event `visibilitychange`, dan menjaga sesi aktif (`media.geckoview.enable-When-In-Background: true` + `keepBackgroundMediaAlive`).
  4. Pasang Universal Fullscreen Video Engine Bridge di `content_shield.js` (`requestFullscreen` patcher + pendeteksi klik tombol fullscreen custom) dan filter banner GIF/plugin iklan WordPress (`ad-inserter`, `wp-quads`, `.gif` eksternal).
- *Catatan #19:* **Elemen YouTube Hilang Saat Fullscreen, Posisi Condong ke Kanan, Layar Blank Saat Keluar Fullscreen, Menu Update di Titik 3 & Tab Hilang Saat Update APK (v1.6.0 -> Fixed v1.7.0)**:
  1. Hapus aturan CSS `*:fullscreen video` dan `div[class*="kln"]` di `content_shield.js` karena menimpa layer kontrol tombol Settings/timeline di dalam `#movie_player:fullscreen` YouTube.
  2. Gunakan `LAYOUT_IN_DISPLAY_CUTOUT_MODE_NEVER` saat landscape fullscreen, set default rasio ke `STANDAR_16_9` (`1.0f, 1.0f`), dan tambahkan `TransformOrigin.Center` agar video tepat di tengah layar tanpa ruang hitam timpang di kiri.
  3. Panggil `geckoView.requestLayout()` dan `geckoView.invalidate()` secara sinkron dan tertunda (`180ms`) di `LaunchedEffect(isFullScreen)` serta `geckoSession.setActive(true)` di `exitFullScreen()` agar `SurfaceView` tidak blank hitam saat kembali ke portrait.
  4. Hapus tombol `"Layar Penuh Video (20:9)"` dari menu titik 3, pindahkan menu **Periksa Update Zenvora** ke menu titik 3 lengkap dengan deteksi rilis terbaru otomatis (`checkForUpdatesSilently` + indikator badge titik oranye), dan simpan seluruh sesi tab secara real-time ke `DataStore` (`saved_tabs_json`) agar tab langsung pulih utuh setelah update APK.
- *Catatan #20:* **Real Fullscreen Terpotong Area Poni Kiri, Pemutar Media Tidak Muncul di QS Panel Android, Scroll Web Kurang Smooth & Kebutuhan Ekstensi uBlock Origin / Store (v1.7.0 -> Fixed v1.8.0)**:
  1. Gunakan `LAYOUT_IN_DISPLAY_CUTOUT_MODE_ALWAYS` (Android 11+) / `LAYOUT_IN_DISPLAY_CUTOUT_MODE_SHORT_EDGES` (Android 9-10), sembunyikan `WindowInsetsCompat.Type.systemBars() or WindowInsetsCompat.Type.displayCutout()`, dan pasang `ViewCompat.setOnApplyWindowInsetsListener(geckoView) { _, insets -> if (isFullScreen) WindowInsetsCompat.CONSUMED else insets }` agar `GeckoView` tidak menerima `safe-area-inset-left` yang menggeser player ke kanan.
  2. Buat `BrowserMediaNotificationManager` yang menghubungkan `org.mozilla.geckoview.MediaSession.Delegate` ke Android `android.media.session.MediaSession` + `Notification.MediaStyle` sehingga pemutar video/musik tampil di Statusbar, Lockscreen, dan QS Panel Android.
  3. Hapus `.offset` pada `BrowserGeckoView` agar `SurfaceView` tetap 100% statis saat scroll (menggunakan overlay toolbar murni) dan aktifkan physics `apz.overscroll.enabled`, `apz.gtk.kinetic_scroll.enabled`, serta `general.smoothScroll` di `gecko-config.yaml`.
  4. Buat `ExtensionManager` & `ExtensionsSheet` (diakses dari menu titik 3) untuk menginstal 1-klik **uBlock Origin**, **Dark Reader**, **SponsorBlock**, **Tampermonkey**, **ClearURLs**, atau menginstal langsung file `.xpi` dari **Mozilla Add-ons Store (`addons.mozilla.org`)**.

  2. Buat `SavedLoginEntity`, `SavedLoginDao`, `ZenvoraDatabase` (v2), dan halaman layar penuh `PasswordManagerSheet` lengkap dengan chip autofill 1-klik di `BrowserScreen` + eksekutor JS `autofillCredentials` di `BrowserSession` + `IMPORTANT_FOR_AUTOFILL_YES` di `BrowserGeckoView`.

  4. Tambahkan panel dropdown **Riwayat & Bookmark Terakhir** ala Chrome di `BrowserOmnibox` saat kolom pencarian difokuskan (`isFocused == true`), lengkap dengan tombol panah `NorthWest` untuk menyalin URL ke kolom ketik dan micro-interactions (`animateFloatAsState` scale + `LocalHapticFeedback`).
  5. Ubah `ExtensionManager.installFromUrl` agar mengunduh paket `.xpi` melalui `OkHttpClient` sambil memancarkan `installProgressPercent` (`0% - 100%`) secara real-time ke `ExtensionsSheet` dan banner mengambang di `BrowserScreen`.
  6. Di `BrowserSession.kt` dan `content_shield.js`, gunakan Desktop Firefox 136 User-Agent khusus saat membuka `addons.mozilla.org`, ubah tombol `"Add to Firefox"` menjadi **"Pasang ke Zenvora"**, dan intercept klik pada tombol instal di fase capture untuk langsung memicu pengunduhan `.xpi` (termasuk ekstensi seperti **Claude Sidebar Free**).
